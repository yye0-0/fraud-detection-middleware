# Dataset attribution and usage

## Workflow integration demo

Puru Lalwani, *Synthetic Financial Datasets for Fraud Detection* (2024), PaySim-style synthetic mobile-money transactions. Dataset card/source: <https://huggingface.co/datasets/purulalwani/Synthetic-Financial-Datasets-For-Fraud-Detection>.

Distributed as `flwrlabs/fed-fraud-paysim-banks` by Flower Labs, CC BY 4.0: <https://huggingface.co/datasets/flwrlabs/fed-fraud-paysim-banks>.

The data and resulting model metrics are synthetic. They are for reproducible workflow demonstration, not customer decisions or production fraud claims.

## Real-data benchmark

The separate benchmark script uses the ULB/Worldline *Credit Card Fraud Detection* dataset mirrored at <https://zenodo.org/records/7395559>. The record describes 284,807 anonymized transactions over two days, including 492 frauds. Download the CSV directly from the source and review its current license/terms before reuse. The dataset is not redistributed in this repository.
